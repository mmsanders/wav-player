# wav-player

A single page for playing WAV files from an iPhone. Uploads stay in this browser (IndexedDB), not in the git repo, so GitHub Pages can host it with no server.

## Pages

Repo Settings, then Pages. Deploy from the `main` branch, folder `/` (root).

Once that is on, the site is [https://mmsanders.github.io/wav-player/](https://mmsanders.github.io/wav-player/).
